## 🧠 Overview

**AirSense-AI** takes one input — the **Air Quality Index (AQI)** — and predicts the concentration of six major air pollutants, along with the overall air-quality category. It is built for quick, interactive testing: enter an AQI value in the Gradio interface and get instant predictions, no coding required.

## 🚀 Features

- ✅ Predicts **CO, NO₂, SO₂, O₃, PM2.5 and PM10** concentrations from AQI
- ✅ Classifies the air-quality level (Good → Hazardous)
- ✅ Clean **Gradio web interface** — runs locally or in the cloud
- ✅ Lightweight **scikit-learn** regression model
- ✅ Ready to deploy on **Hugging Face Spaces**

## ⚙️ How It Works

1. The model is trained on historical AQI and pollutant data (see `notebook.ipynb`).
2. A multi-output regression model learns the relationship between AQI and each pollutant gas.
3. The trained model is saved as `model/aqi_model.pkl` and loaded by the Gradio app.
4. Enter an AQI value → the app predicts all six pollutant concentrations and maps the AQI to its category:

| AQI Range | Air-Quality Level |
|-----------|-------------------|
| 0 – 50    | Good 🌿 |
| 51 – 100  | Moderate 😊 |
| 101 – 200 | Unhealthy for Sensitive Groups 😷 |
| 201 – 300 | Unhealthy ☠️ |
| 301 – 400 | Very Unhealthy 💀 |
| 400+      | Hazardous 🚫 |

## ▶️ Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/aedwinbobby/AI-AQI-Predictor.git
cd AI-AQI-Predictor

# 2. Install dependencies
pip install -r requirements.txt

# 3. Train the model (run notebook.ipynb) — this generates model/aqi_model.pkl

# 4. Launch the app
python app.py
```
