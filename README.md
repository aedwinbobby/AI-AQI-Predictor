# AI-AQI-Predictor
AI model that predicts pollutant gas levels (CO, NO₂, SO₂, O₃, PM₂.5, etc.) and determines Air Quality Level when given the AQI as input. It also includes a Gradio web interface for easy testing.

## 🧠 Overview
**AirSense-AI** is an intelligent regression model that predicts the **concentration of major air pollutants** (CO, NO₂, SO₂, O₃, PM₂.5, PM10) and determines the **air-quality level** based solely on the **Air Quality Index (AQI)**.  
The app uses a **Gradio web interface** for quick, interactive predictions — no coding required.

---

## 🚀 Features
✅ Predicts pollutant gas values from AQI  
✅ Displays air-quality category (Good / Moderate / Unhealthy etc.)  
✅ Built with **scikit-learn + Gradio**  
✅ Ready to deploy on **Hugging Face Spaces** or **GitHub Pages**  
✅ Lightweight – runs locally or in the cloud
